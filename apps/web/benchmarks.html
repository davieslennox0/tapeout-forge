Forgeout vs. the public 39-circuit set

Benchmarked against nand.aihashrate.stream/circuits/ (39 real on-chain circuits, 16 on BSC + 23 on X Layer, all pure NAND / 0 latches). This page covers the 23 X Layer circuits. Every netlist was fetched directly from its own processor contract on-chain, optimized, and independently re-verified equivalent before being counted — not trusted from the optimizer's own internal check.

Gas estimates use the published energy-additive law E_step = α + β_N·N_NAND + β_L·N_LATCH + β_in·n_in + β_out·n_out and X Layer constants from nand.aihashrate.stream/physics/ (α=20,319, β_N=2,280.82, β_L=3,179.81, β_in=324.71, β_out=−1,237.10 gas), read 2026-11-18.

Not every circuit here is a real function — some are the source site's own physics-measurement constructions (long single-input NAND chains, mass-duplicated parallel gates). Optimizing those isn't a meaningful demo of anything, so this page classifies each circuit (reasons below) and reports functional circuits as the headline, with probe circuits shown separately.
